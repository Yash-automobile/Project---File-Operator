# Journal Manager

## About

A simple Python project to add and store journal entries in a text file.

## Features

* Add journal entry
* View journal entries
* Save date and time
* Store data in `journal.txt`

## Technologies

* Python
* OOP
* File Handling
* `os`
* `datetime`

## Files

* `journal.py` – Main program
* `journal.txt` – Stores entries
* `README.md` – Project information

## How to Run

1. Open the project in VS Code.
2. Run `journal.py`.
3. Follow the instructions.
